================================================================================
RÉSUMÉ STATISTIQUES
================================================================================

Total Endpoints: 100+
Principaux Contrôleurs:
  - AdminController: Gestion globale, day management, users, tables, payments
  - HomeController: Factures, ventes, compteurs
  - ProductController: Produits, catégories, stock, mouvements
  - InventoryController: Inventaires
  - ReservationController: Réservations hôtel
  - ReportController: Rapports
  - UserController: Utilisateurs, authentification
  - CommandesController: Commandes
  - SettingController: Paramètres, liaison

Permissions principales:
  - ouvrir-journee
  - cloturer-journee
  - voir-utilisateurs, creer-utilisateurs, modifier-utilisateurs, supprimer-utilisateurs
  - voir-categories, creer-categories
  - voir-produits, creer-produits, modifier-produits
  - voir-mouvements-stock, creer-mouvements-stock, supprimer-mouvements-stock
  - voir-emplacements, creer-emplacements
  - voir-tables, creer-tables
  - voir-factures, creer-factures
  - voir-ventes
  - voir-chambres
  - voir-serveurs

Middlewares:
  - auth: Authentification requise
  - check.day.access: Vérification accès journée
  - can: Vérification permissions

================================================================================
Notes importantes:
- Tous les endpoints sont protégés par le middleware 'auth' sauf indication contraire
- Les permissions sont gérées via le middleware 'can' pour les actions sensibles
- Les routes API sont prêtes pour l'expansion (CORS activé)
- Les emplacements peuvent être de type 'table' ou 'hôtel'
- Les routes de vues (Route::view) affichent les interfaces front-end
